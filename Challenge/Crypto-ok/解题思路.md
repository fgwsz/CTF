这是一个典型的 **Ook! 编程语言** 题目.Ook! 是一种基于 Brainfuck 的深奥编程语言,
用 `Ook.`|`Ook?`|`Ook!` 和空格|换行来组合指令.

## 🔍 识别特征
`file.txt` 中,全是 `Ook.`|`Ook?`|`Ook!,这正是 Ook! 的标准格式.

## 🧠 解法步骤

1. **转换规则**  
   Ook! 的指令由两个单词组成,对应 Brainfuck 符号如下:

   | Ook! 指令 | Brainfuck |
   |-----------|-----------|
   | `Ook. Ook?` | `>` |
   | `Ook? Ook.` | `<` |
   | `Ook. Ook.` | `+` |
   | `Ook! Ook!` | `-` |
   | `Ook! Ook.` | `.` |
   | `Ook. Ook!` | `,` |
   | `Ook! Ook?` | `[` |
   | `Ook? Ook!` | `]` |

2. **提取并转换**  
   把文件中的空格和换行保留为指令分隔符,按两个 `Ook` 词汇为一组进行映射.

3. **运行 Brainfuck**  
   转换后得到 Brainfuck 代码,运行即可得到 Flag.

## 解题
直接使用工具`ook_bf_interpreter.py`进行`ook`/`brainfuck`编程语言的解释执行.
```bash
$ python ../../Tools/Crypto-ook_bf_interpreter/ook_bf_interpreter.py -i file.txt

```
