## 🧠 Brainfuck 执行原理

Brainfuck 程序操作一个**字节数组(内存)**和一个**数据指针**,指令集只有 8 个字符:

| 指令 | 操作 |
|------|------|
| `>`  | 数据指针右移一格 |
| `<`  | 数据指针左移一格 |
| `+`  | 当前单元的值加 1(模 256) |
| `-`  | 当前单元的值减 1(模 256) |
| `.`  | 输出当前单元的 ASCII 字符 |
| `,`  | 从标准输入读取一个字节存入当前单元(CTF 中常忽略) |
| `[`  | 如果当前单元值为 0,跳转到匹配的 `]` 之后 |
| `]`  | 如果当前单元值不为 0,跳转到匹配的 `[` 之前 |

执行时,解释器维护:
- `unsigned char memory[30000]`(标准大小)
- `int ptr = 0`(数据指针)
- `int ip = 0`(指令指针,遍历程序字符串)

遇到 `[` 或 `]` 时,需要找到匹配的另一半,
可以用**栈**预处理括号位置,或在运行时动态查找.

---

## 🛠️ C++ 实现方案

我们采用**预扫描括号匹配**的方法,
将程序字符串中 `[` 和 `]` 的配对位置存入一个数组 `jump[code.size()]`,
这样在执行时可以直接跳转,效率更高.

### 完整 C++ 代码

```cpp
#include <iostream>
#include <fstream>
#include <vector>
#include <stack>
#include <string>
#include <cstring>

class BrainfuckInterpreter {
private:
    static const int MEM_SIZE = 30000;
    unsigned char memory[MEM_SIZE];
    int ptr;
    std::string code;
    std::vector<int> jump;   // jump[i] 是匹配的括号位置

    void preprocess() {
        std::stack<int> st;
        jump.assign(code.size(), -1);
        for (size_t i = 0; i < code.size(); ++i) {
            if (code[i] == '[') {
                st.push(i);
            } else if (code[i] == ']') {
                if (st.empty()) {
                    throw std::runtime_error("错误:多余的 ']'");
                }
                int open = st.top(); st.pop();
                jump[open] = i;
                jump[i] = open;
            }
        }
        if (!st.empty()) {
            throw std::runtime_error("错误:未匹配的 '['");
        }
    }

public:
    BrainfuckInterpreter(const std::string& src) : code(src), ptr(0) {
        std::memset(memory, 0, sizeof(memory));
        // 过滤出有效的 Brainfuck 指令
        std::string filtered;
        for (char c : code) {
            if (strchr("><+-.,[]", c)) {
                filtered.push_back(c);
            }
        }
        code = filtered;
        preprocess();
    }

    std::string run() {
        std::string output;
        size_t ip = 0;
        while (ip < code.size()) {
            char cmd = code[ip];
            switch (cmd) {
                case '>': ++ptr; break;
                case '<': --ptr; break;
                case '+': ++memory[ptr]; break;
                case '-': --memory[ptr]; break;
                case '.': output.push_back(memory[ptr]); break;
                case ',': {
                    char c = std::cin.get();
                    memory[ptr] = (c == EOF) ? 0 : static_cast<unsigned char>(c);
                    break;
                }
                case '[':
                    if (memory[ptr] == 0) {
                        ip = jump[ip];  // 跳到匹配的 ']' 之后
                    }
                    break;
                case ']':
                    if (memory[ptr] != 0) {
                        ip = jump[ip];  // 跳回匹配的 '['
                    }
                    break;
            }
            ++ip;
        }
        return output;
    }
};

int main(int argc, char* argv[]) {
    if (argc != 2) {
        std::cerr << "用法: " << argv[0] << " <brainfuck程序文件>" << std::endl;
        return 1;
    }

    std::ifstream file(argv[1]);
    if (!file.is_open()) {
        std::cerr << "无法打开文件: " << argv[1] << std::endl;
        return 1;
    }
    std::string code((std::istreambuf_iterator<char>(file)),
                      std::istreambuf_iterator<char>());
    file.close();

    try {
        BrainfuckInterpreter bf(code);
        std::string result = bf.run();
        std::cout << result;
    } catch (const std::exception& e) {
        std::cerr << "执行错误: " << e.what() << std::endl;
        return 1;
    }
    return 0;
}
```

## 📦 编译与使用

1. **保存上述代码**为 `bf.cpp`.
2. **编译**:
   ```bash
   g++ -std=c++11 -O2 bf.cpp -o bf
   ```
3. **运行**:
   ```bash
   ./bf hello.bf
   ```
   其中 `hello.bf` 是一个 Brainfuck 源文件,例如经典的 "Hello World!".

4. **测试**:你可以创建一个 `hello.bf` 文件,内容为:
   ```
   ++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
   ```
   然后运行 `./bf hello.bf`,应该输出 `Hello World!`.

## 🔍 扩展与优化

- **内存大小可配置**:将 `MEM_SIZE` 改为变量,通过构造函数参数传入.
- **调试支持**:可以在执行时打印当前指令和内存状态.
- **性能提升**:用 `std::vector<unsigned char>` 动态扩展内存,避免硬编码.
- **支持从标准输入直接读取程序**(类似管道).

用 C++ 编写 Brainfuck 解释器非常直接,核心难点仅在于**括号匹配和循环跳转**.
上面的实现清晰|健壮,足以应对 CTF 中常见的 Brainfuck 题目.
