## 📝 列置换密码(Columnar Transposition Cipher)

### 一|基本概念
列置换密码是一种**古典对称加密算法**,它不改变明文字符本身,
而是通过**重新排列字符的位置**来打乱信息顺序,
属于**置换密码(Transposition Cipher)**的一种.

- **核心思想**:将明文按固定宽度(密钥长度)写成矩阵,
然后按照密钥指定的列顺序重新读取,得到密文.
- **密钥**:通常是一个数字序列(如 `2 1 6 5 3 4`),表示列的读取或写入顺序.

---

### 二|加密过程
**步骤**:
1. **确定密钥**:密钥是一个包含 **1~n** 每个数字一次的排列,
例如 `[2, 1, 6, 5, 3, 4]`,表示列宽 `n=6`.
2. **填充矩阵**:将明文字符从左到右|从上到下依次填入 **n 列** 的矩阵中,
最后一行若不足,可填充任意字符(如 `@`|`x`)或不处理.
3. **按密钥顺序读取列**:根据密钥顺序,依次将对应列的字符从上到下读出,拼接成密文.

**示例**(密钥 `[2, 1, 6, 5, 3, 4]`,明文 `flag{5...`):
- 明文(前12个字符):`flag{52048c45`  
- 矩阵(6列,2行):
  ```
  列号:  1  2  3  4  5  6
  ┌─────────────────────┐
  │ f  l  a  g  {  5   │  第1行
  │ 2  0  4  8  c  4   │  第2行
  └─────────────────────┘
  ```
- 按密钥列顺序读取:先读第2列(`l0`),再读第1列(`f2`),再读第6列(`54`),第5列(`{c`),
第3列(`a4`),第4列(`g8`).
- 密文:`l0f254{ca4g8`(实际原题更复杂,此处仅为示意).

> **注意**:不同实现可能先按行写入再按列读取,或先按列写入再按行读取,原理相通.

---

### 三|解密过程
解密是加密的逆过程,需要知道**密钥**和**矩阵列数**.

**步骤**:
1. **计算矩阵尺寸**:密文长度除以密钥长度,得到行数.
2. **还原矩阵**:根据密钥顺序,将密文字符按列填充回矩阵的对应列中.
3. **按行读取**:从矩阵的第一行开始,从左到右逐行读出,
即为明文(末尾填充字符需移除).

**加密与解密密钥的关系**:
- 如果加密时密钥 `E = [2,1,6,5,3,4]`(表示读取列的顺序),
解密密钥 **必须使用其逆置换(Inverse Permutation)**.
- 求逆方法:`D[i]` = 在 `E` 中数字 `i` 的位置(索引从1开始).
- 例如 `E = [2,1,6,5,3,4]`,其逆 `D = [2,1,5,6,4,3]`(对应原题解密密钥).

我有一个新的思路运用同一个密钥进行加密和解密:

加密过程:

flag{5 ->密钥[2,1,6,5,3,4]加密时的涵义:
密钥中inde=1,value=2代表原文第2个字符放到加密后的串的第1位.
```txt
flag{5->lf5{ag
123456  216534
```
解密过程:
密钥[2,1,6,5,3,4]解密时的涵义:
密钥中index=1,value=2代表对应密文第1个字符是原文的第2位.
```txt
lf5{ag ->flag{5
216534
```

**为什么必须用逆?**
- 加密时,明文第1列被读到密文第2位,加密密钥 `[2,...]` 
表示"把明文第1位移到密文第2位".
- 解密时,要从密文第2位取回明文第1位,因此解密序列的第一个数字必须是 `2`,
以此类推.

---

### 四|安全性与特点
| 优点 | 缺点 |
|------|------|
| 简单高效,不依赖复杂数学运算 | **纯置换密码**易被词频分析或暴力破解(若密钥长度短) |
| 可以与其他密码(如凯撒)组合增强安全性 | 密钥管理问题:若密钥泄露,所有密文可破 |
| 实现容易,适合简单混淆 | 对长密钥(>20)安全性较高,但加密速度下降 |

---

### 五|CTF 实战小技巧
- **识别特征**:密文与明文使用相同字符集,且字符频率分布完全一致(只是顺序乱).
- **已知明文攻击**:若知道部分明文(如 `flag{`),
可直接反推出解密置换顺序,无需计算逆置换.
- **暴力破解**:当密钥长度 n 较小时(如 ≤10),
可枚举所有 n! 种排列,用正则匹配 `flag{` 秒出结果.

---

### 六|总结
列置换密码通过**位置置换**实现加密,解密时需使用加密密钥的**逆置换**.
它与栅栏密码都属于置换类,但栅栏是固定模式的分组交错,
而列置换由密钥灵活控制分组和读取顺序,更复杂也更安全.
