# `/.-`解题思路

看到题目描述:
```
..-./.-../.-/--./----.--/-../...--/..-./-.-./-.../..-./.----/--.../..-./----./...--/----./----./...../-----/....-/-----.-
```
`.-`结构让我想到了可能是`MORSE`密码(摩斯密码),`/`可能是字符之间的分隔符

下面是标准的摩斯密码对照表,供你参考使用.

## 🔤 字母 A - Z

| K | -.- | X | -..- |
| L | .-.. | Y | -.-- |
| M | -- | Z | --.. |

## 🔢 数字 0 - 9
所有数字的摩斯密码都由**5位**点划组成.
*   **1-5**:开头是几个点,剩余用划补齐(例如:3 = ...--).
*   **6-0**:开头是几个划,剩余用点补齐(例如:6 = -....,0 = -----).

| 数字 | 摩斯密码 | 数字 | 摩斯密码 |
| :--- | :--- | :--- | :--- |
| 1 | .---- | 6 | -.... |
| 2 | ..--- | 7 | --... |
| 3 | ...-- | 8 | ---.. |
| 4 | ....- | 9 | ----. |
| 5 | ..... | 0 | ----- |

## 解题
根据对照表手动解析如下字符串
```
..-./.-../.-/--./----.--/-../...--/..-./-.-./-.../..-./.----/--.../..-./----./...--/----./----./...../-----/....-/-----.-
```
或者直接使用工具`morse_cli.py`解码得到:
```bash
$ python3 ../../Tools/Crypto-morse_cli/morse_cli.py decode "..-./.-../.-/--./----.--/-../...--/..-./-.-./-.../..-./.----/--.../..-./----./...--/----./----./...../-----/....-/-----.-" -c "/"
FLAG[?----.--]D3FCBF17F9399504[?-----.-]
```
有2个字符没有解析成功,但是我们可以直接根据以往的`flag{xxxxx}`的经验得知,
未解析的2个字符就是大括号的左右括号.

因此我们得到了`FLAG{D3FCBF17F9399504}`,提交发现不正确.

试一下转换为小写字母`flag{d3fcbf17f9399504}`,再次提交,正确通过.
