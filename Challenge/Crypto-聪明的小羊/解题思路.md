# Crypto-聪明的小羊-解题思路

题目描述:

一只小羊翻过了2个栅栏 fa{fe13f590lg6d46d0d0}

根据题目描述,这个一定是和栅栏密码相关.

## 栅栏密码的加密原理

### 加密步骤

选择栏数(密钥):通常为2到10行,栏数越多,加密路径越复杂.

#### 之字型流派

绘制栅栏:将明文按锯齿形写入各栏.

例如,明文`HELLO WORLD`,选择3栏:

第1行:`H---O---L-`

第2行:`-E-L-W-R-D`

第3行:`--L---O---`

明文: `HELLOWORLD`

按行读取:逐行拼接字符,忽略空格,得到密文`HOLELWRDLO`.

#### 分组流派

绘制栅栏:将明文按暗顺序分组写入各栏.

例如,明文`HELLO WORLD`,选择3栏:

第1行:`H--L--O--D`

第2行:`-E--O--R--`

第3行:`--L--W--L-`

明文: `HELLOWORLD`

按行读取:逐行拼接字符,忽略空格,得到密文`HLODEORLWL`.

### 解密步骤

确定栏数(密钥).

计算每栏字符数,将密文分割成对应片段.

按锯齿形填充栅栏网格.

沿原加密路径读取,恢复明文 

如果密钥未知,可尝试所有可能栏数(2到文本长度)进行暴力破解.

题目:
一只小羊翻过了2个栅栏 fa{fe13f590lg6d46d0d0}

栅栏为2

看到有`f`和`l`字符,那么按照`flag`的顺序,

第二行的首字母一定是`l`,于是手动分组.

根据`flag`字母的顺序得知,
在栅栏为2时之字型流派还是分组流派加密方式等价.

因此,选其中一种顺序解密即可.

第一行:`f-a-{-f-e-1-3-f-5-9-0-`

第二行:`-l-g-6-d-4-6-d-0-d-0-}`

明文  :`flag{6fde4163df05d900}`

由此,解题成功.

也可以使用`rail_fence.py`直接进行解密.
```bash
$ python3 ../../Tools/Crypto-rail_fence/rail_fence.py -d "fa{fe13f590lg6d46d0d0}" -k 2
flag{6fde4163df05d900}
```
