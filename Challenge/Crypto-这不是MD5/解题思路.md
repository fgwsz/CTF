# Crypto-这不是MD5-解题思路

题目描述:
```
666c61677b616537333538376261353662616566357d
```
我数了一下正好是`44`位,不是`32`位十六进制,所以排除`MD5`密文的可能性.

因为密文的字符取值范围`[0-9|a-z|A-Z]`,所以初步怀疑是`base64`编码.

使用工具`base64_tool.py`进行解码看一下:
```bash
python3 ../../Tools/Crypto-base64_tool/base64_tool.py -d "666c61677b616537333538376261353662616566357d"
[提示] 解码结果不是有效 UTF-8 文本，已转十六进制显示
ebae9ceb5ebbedbeb5eb9dfbdf7df9dfcdfbeb6eb5df9dfaeb6eb5eb9ebadf9edd
```
看来并不是`base64`编码.

这里思考,它是不是一个简单的十六进制串?
```
66 6c 61 67 7b 61 65 37 33 35 38 37 62 61 35 36 62 61 65 66 35 7d
```
