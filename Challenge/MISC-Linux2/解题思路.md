# MISC-Linux2-解题思路

题目描述:
```
给你点提示吧：key的格式是KEY{}
```

首先检查一下`file.zip`的文件头信息:
```bash
$ file file.zip
file.zip: Zip archive data, at least v2.0 to extract, compression method=deflate
```
使用资源管理器看一下`file.zip`的备注信息:没有备注.

接下来解压看一下文件内容:
```bash
$ unzip file.zip -d export
Archive:  file.zip
  inflating: export/brave            

$ tree export
export
└── brave

0 directories, 1 file
```
检查一下`export/brave`的文件头
```bash
$ file export/brave
export/brave: Linux rev 1.0 ext3 filesystem data, UUID=cf6d7bff-c377-403f-84ae-956ce3c99aaa
```
又是一个ext3文件系统镜像文件.它可以直接使用`strings`提取信息.

使用资源管理器检查一下`export/brave`的备注信息:没有备注信息.

检查一下`export/brave`的二进制可打印字符串信息有没有`KEY{}`格式
```bash
$ strings export/brave | rg KEY
KEY{24f3627a86fc740a7f36ee2c7a1c124a}
KEY{}
```
提交`KEY{24f3627a86fc740a7f36ee2c7a1c124a}`,提示通过.

至此,解题完毕.
