至此,我们发现可疑的文件是`gzip`和`PNG`文件.
编写一个解压脚本`extract_gzip.sh`,对每个`gzip`文件进行解压,导出到统一目录.
```bash
#!/bin/bash
set -euo pipefail

# 脚本所在目录
script_dir=$(dirname "$(readlink -f "$0")")
cd "$script_dir"

# 解压输出根目录
output_root="export/extracted"
mkdir -p "$output_root"

# 遍历 export 下所有普通文件(包括隐藏文件)
find export -type f -print0 | while IFS= read -r -d '' file; do
    # 用 file 命令检测 MIME 类型,识别 gzip
    if file -b --mime-type "$file" | grep -q '^application/gzip$'; then
        echo "正在解压: $file"

        # 构造输出路径:保留相对目录结构,添加 .extracted 后缀以防重名
        relative_path="${file#export/}"          # 去掉 export/ 前缀
        target="$output_root/$relative_path.extracted"
        target_dir="$(dirname "$target")"
        mkdir -p "$target_dir"

        # 解压到目标文件(-c 输出到 stdout,重定向)
        if gunzip -c "$file" > "$target" 2>/dev/null; then
            echo "  解压成功 -> $target"
        else
            echo "  解压失败: $file" >&2
        fi
    fi
done

echo "全部处理完毕,解压文件位于: $output_root"
```

## `gzip` 拓展知识
`.gz` 是 **gzip**(GNU zip)压缩格式的扩展名.
它使用 **DEFLATE** 算法进行压缩,
核心特点是 **只压缩单个文件**(或标准输入流),不具备文件打包功能.

在 Linux 环境下,操作非常简单:

### 1. 压缩(创建 .gz 文件)

- **基本用法**(压缩后删除原文件):
  ```bash
  gzip filename.txt
  ```
  执行后,`filename.txt` 消失,变为 `filename.txt.gz`.

- **保留原文件**(常用):
  ```bash
  gzip -k filename.txt
  ```
  或使用 `-c` 重定向:
  ```bash
  gzip -c filename.txt > filename.txt.gz
  ```

- **压缩标准输入**(比如管道传过来的数据):
  ```bash
  cat log.txt | gzip > log.txt.gz
  ```

---

### 2. 解压(还原 .gz 文件)

- **基本用法**(解压后删除 .gz 文件):
  ```bash
  gunzip filename.txt.gz
  ```
  执行后,`filename.txt.gz` 消失,变为 `filename.txt`.

- **保留压缩包**(常用):
  ```bash
  gunzip -k filename.txt.gz
  ```
  或使用 `gzip -d -k`.

- **输出到标准输出**(**最常用,且不改变原文件**):
  ```bash
  gunzip -c filename.txt.gz > output.txt
  ```
  这会将解压后的数据直接打印到终端,我们用 `>` 重定向到文件.
**这就是脚本里 `gunzip -c "$file" > target` 的原理**.

---

### 3. 验证与测试(不解压,只检查)

- **查看压缩包内容**(不解压):
  ```bash
  gunzip -l file.gz   # 显示压缩前后的字节数
  gunzip -t file.gz   # 测试完整性,无输出则正常
  ```

---

### ⚠️ 关键区别:`.gz` 与 `.tar.gz`

| 格式 | 本质 | 解压命令 |
|------|------|----------|
| `.gz` 或 `file.dat`(实际是gzip) | **单个文件**的压缩流 | `gunzip -c file > output` |
| `.tar.gz` 或 `.tgz` | **多个文件/目录**先打包成 `.tar`,再压缩 | `tar -xzf file.tar.gz` |

**特别注意**:如果你对普通的 `.gz` 文件执行 `tar -xzf`,会报错
(因为它不是一个 `tar` 归档).

反之,如果你对 `.tar.gz` 执行 `gunzip`,虽然能解压出 `.tar` 文件,
但你还得再用 `tar -xf` 解包.

### 针对你遇到的场景(无扩展名文件)

你遇到的 `level.dat` 虽然不以 `.gz` 结尾,
但 `file` 命令识别出它是 `gzip compressed data`.

此时你只能根据**文件头魔数**(`1F 8B`)来判断,
而不能看扩展名.

使用 `gunzip -c` 处理这些文件是完全正确的,
因为 `gunzip` 不看扩展名,只认数据头.
