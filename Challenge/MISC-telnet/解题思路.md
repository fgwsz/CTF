# MISC-telnet-解题思路
首先检查一下`telnet.zip`的文件头信息
```bash
$ file telnet.zip
telnet.zip: Zip archive data, at least v2.0 to extract, compression method=deflate
```
然后解压到`export/`目录下.
```bash
$ mkdir export
$ unzip telnet.zip -d export/
Archive:  telnet.zip
  inflating: export/networking.pcap  
$ tree export
export
└── networking.pcap

0 directories, 1 file
```
简单检查一下`networking.pcap`的文件头和文件内容:
```bash
$ file export/networking.pcap 
export/networking.pcap: pcap capture file, microsecond ts (little-endian) - version 2.4 (Ethernet, capture length 65535)
$ strings export/networking.pcap 
38400,38400
XTERM
Ubuntu 12.04.2 LTS
hockeyinjune-virtual-machine login: 
Password: 
flag{d316759c281bf925d600be698a4973d5}
Login incorrect
hockeyinjune-virtual-machine login: 
```
我们发现了`flag{d316759c281bf925d600be698a4973d5}`字符串,
上面的`Login incorrect`也提示我们登录失败,
这意味着`flag{d316759c281bf925d600be698a4973d5}`可能是错误的.

我们还是先尝试提交一下,提示正确.

这里设想一下如果上述`flag`是错误的,接下来该怎么办呢?

使用`wireshark`来打开`export/networking.pcap`进行网络对话分析.
`file>open`打开`export/networking.pcap`,
然后使用`Analyze>Follow>TCP Stream`查看`ASCII`/`Row`信息.

如果信息中没有可用内容,就对整个对话中可疑的数据交换进行数据下载.
以此来找到有用的信息.

答题结束,以上.
