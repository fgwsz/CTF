# MISC-宽带信息泄漏-解题思路
网址:
<https://ctf.bugku.com/challenges/detail/id/9.html>

题目描述:
```
描述:flag{宽带用户名}
```

资源:
`conf.zip`

## 解题过程
检查一下`conf.zip`的文件头:
```bash
$ file conf.zip
conf.zip: Zip archive data, at least v2.0 to extract, compression method=deflate
```
使用资源管理器检查一下`conf.zip`的文件属性,备注信息:没有备注信息.

使用`strings`检查一下是否含有`flag`二进制信息.
```bash
$ strings conf.zip | rg flag
$
```
没有找到`flag`信息.

使用`binwalk`检查一下`conf.zip`是否含有文件拼接行为.
```bash
$ binwalk conf.zip

DECIMAL       HEXADECIMAL     DESCRIPTION
--------------------------------------------------------------------------------
0             0x0             Zip archive data, at least v2.0 to extract, compressed size: 8864, uncompressed size: 15272, name: conf.bi
n
8992          0x2320          End of Zip archive, footer length: 22
```
`conf.zip`没有文件拼接行为,是正常的压缩包.

解压`conf.zip`文件内容到`export`目录下.
```bash
$ unzip conf.zip -d export
Archive:  conf.zip
  inflating: export/conf.bin         

$ tree export
export
└── conf.bin

0 directories, 1 file
```
然后检查一下`export/conf.bin`的内容.
```bash
$ file export/conf.bin 
export/conf.bin: data

$ strings export/conf.bin | rg usr

$ strings export/conf.bin | rg user

$ strings export/conf.bin | rg flag

$ binwalk export/conf.bin 

DECIMAL       HEXADECIMAL     DESCRIPTION
--------------------------------------------------------------------------------

```
看起来毫无头绪.
`export/conf.bin`是一个纯粹的二进制串.

询问ai和查询相关资料得知,`export/conf.bin`是一个路由器配置文件.

需要使用`RouterPassView.exe`打开
(已经下载到`../../Tools/MISC-RouterPassView/`目录下).

在`linux`下使用`wine`运行`RouterPassView.exe`,
运行软件后,使用`File>Open Router Config File`加载`export/conf.bin`文件.

然后就会看到一个`xml`结构的可读文件内容.(已保存为`conf.bin.xml`)


按照题目描述,flag内容是宽带用户名.

因此使用`ripgrep`搜索`conf.bin.xml`内的用户名字符串,结果如下:
```bash
$ rg user conf.bin.xml 

$ rg User conf.bin.xml 
22:    <X_TP_UserCfg>
24:    </X_TP_UserCfg>
213:          <Username val=053700357621 />

$ rg usr conf.bin.xml 

$ rg Usr

```
接下来,继续查看`conf.bin.xml`的`22-24`行.
```txt
22    <X_TP_UserCfg>
23      <AdminPwd val=123456789 />
24    </X_TP_UserCfg>
```
至此,我们锁定了2个可能的flag:
`flag1`:`flag{053700357621}`和`flag2`:`flag{123456789}`.

提交`flag1`,提交通过,解答完毕.
