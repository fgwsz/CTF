## 社会主义核心价值观编码/解码学习笔记

### 一、背景概述

社会主义核心价值观编码（也称“核心价值编码”或“24字编码”）是一种基于中文语境的自定义编码方案，常见于 CTF（Capture The Flag）竞赛或信息安全趣味挑战中。它利用社会主义核心价值观的 **24 个字** 作为编码字符集，将任意 UTF-8 文本转换为由这些汉字组成的字符串，从而实现信息的隐藏或传输。

本笔记参考掘金社区文章《社会主义核心价值观解密》（https://juejin.cn/post/7530957239852072998），详细阐述其编码与解码的完整流程。

---

### 二、编码字符集

核心价值观共 24 个字，分为 12 个词汇，每个词汇作为一个编码单元（索引 0~11）：

| 索引 | 词汇 |
| :---: | :---: |
| 0 | 富强 |
| 1 | 民主 |
| 2 | 文明 |
| 3 | 和谐 |
| 4 | 自由 |
| 5 | 平等 |
| 6 | 公正 |
| 7 | 法治 |
| 8 | 爱国 |
| 9 | 敬业 |
| 10 | 诚信 |
| 11 | 友善 |

在编码过程中，每个词汇被当作一个 **符号**，即编码后的字符串由这些两字词汇拼接而成（如“富强民主文明和谐”）。

### 三、编码过程（编码器）

#### 1. 核心思想

将原始文本的 **UTF-8 字节序列** 转换成 **十六进制字符串**，然后对每个十六进制字符（0~F）进行映射，得到一系列索引值（0~11），最后将索引替换为对应的词汇。

#### 2. 详细步骤

##### 步骤 1：UTF-8 编码
将输入文本（例如 “我”）转换为 UTF-8 字节序列。
- 示例：`"我"` → UTF-8 字节为 `E6 88 91`（十六进制表示为 `E68891`）。

##### 步骤 2：生成十六进制字符串
将字节序列的十六进制表示以字符串形式呈现，全部大写。
- 示例：`E68891`

##### 步骤 3：逐字符映射
遍历十六进制字符串的每个字符（每个字符是一个十六进制数字，取值范围 0~F），根据其数值进行处理：

- **若数值 0~9**：直接将该数值作为索引（0~9）保存。
- **若数值 10~15（即 A~F）**：随机选择以下两种规则之一，生成两个索引值：

  | 数值 n | 规则一（概率 50%） | 规则二（概率 50%） |
  | :---: | :---: | :---: |
  | A (10) | [11, 4] | [10, 0] |
  | B (11) | [11, 5] | [10, 1] |
  | C (12) | [11, 6] | [10, 2] |
  | D (13) | [11, 7] | [10, 3] |
  | E (14) | [11, 8] | [10, 4] |
  | F (15) | [11, 9] | [10, 5] |

  例如，`E` 若选规则一 → `[11, 8]`；若选规则二 → `[10, 4]`。

- **为什么这样设计？** 为了确保解码时能够唯一还原，规则一和规则二分别使用索引 `11` 和 `10` 作为“前导标记”，后续索引与原始值有固定运算关系，解码时可反向推导。

##### 步骤 4：索引转词汇
将得到的所有索引值依次替换为对应的词汇（表 1），拼接成一个完整的字符串。

##### 步骤 5：输出编码结果
编码结果是一个仅包含 12 个词汇（共 24 个汉字）的字符串，无空格或分隔符。

#### 3. 编码示例

**输入**：`"我"`  
UTF-8 十六进制：`E68891`  
逐个字符处理：

1. `E`（14）→ 随机选规则一 → `[11, 8]` → 对应 `友善`、`爱国`  
2. `6` → 直接索引 `6` → 对应 `公正`  
3. `8` → 索引 `8` → 对应 `爱国`  
4. `8` → 索引 `8` → `爱国`  
5. `9` → 索引 `9` → `敬业`  
6. `1` → 索引 `1` → `民主`

最终编码串：`友善爱国公正爱国爱国敬业民主`  
（注意：由于随机性，每次编码可能不同，例如可能得到 `诚信自由公正爱国爱国敬业民主`，但均可解码回原文本）

### 四、解码过程（解码器）

解码是编码的逆过程，但必须能够处理两种不同规则生成的编码串，而无需额外信息。

#### 1. 核心步骤

##### 步骤 1：词汇拆分
将编码串按每两个汉字（即一个词汇）分组，得到一个词汇序列。

##### 步骤 2：词汇查表
将每个词汇映射到其索引（0~11），得到索引序列。

##### 步骤 3：还原十六进制字符
从左到右遍历索引序列，根据索引值判断如何还原：

- **若当前索引 `idx < 10`**：表示该索引直接对应一个十六进制数字（0~9），将其转换为字符 `str(idx)`，然后指针后移一位。
- **若当前索引 `idx == 10`**：表示该位置为规则二的前导符，规则二格式为 `[10, n-10]`，其中 `n` 为原始十六进制值（10~15）。因此，下一个索引 `next` 的值等于 `n - 10`，所以原始值 `n = next + 10`。将该值转换为十六进制字符（A~F），指针后移两位。
- **若当前索引 `idx == 11`**：表示该位置为规则一的前导符，规则一格式为 `[11, n-6]`，因此 `n = next + 6`。同样转换为十六进制字符，指针后移两位。

##### 步骤 4：拼接十六进制字符串
将所有还原出的十六进制字符按顺序拼接，得到完整的十六进制字符串。

##### 步骤 5：字节解码
将十六进制字符串转换为字节序列，再按 UTF-8 解码为原始文本。

#### 2. 解码示例

**编码串**：`友善爱国公正爱国爱国敬业民主`  
拆分为词汇：`友善`、`爱国`、`公正`、`爱国`、`爱国`、`敬业`、`民主`  
查表得索引序列：`[11, 8, 6, 8, 8, 9, 1]`

遍历：
- `11` → 规则一，取下一个 `8` → `n = 8 + 6 = 14` → 十六进制字符 `E`
- `6` → 直接 → 字符 `6`
- `8` → 直接 → 字符 `8`
- `8` → 直接 → 字符 `8`
- `9` → 直接 → 字符 `9`
- `1` → 直接 → 字符 `1`

得到十六进制串：`E68891`  
字节解码：`E6 88 91` → UTF-8 → `"我"` ✅

### 五、算法特点

| 特点 | 说明 |
| :--- | :--- |
| **非确定性编码** | 同一个文本每次编码结果可能不同（由于随机选择规则），增加了编码的多样性。 |
| **确定性解码** | 无论使用哪种规则，解码结果唯一且正确。 |
| **基于 UTF-8** | 支持所有 Unicode 字符，不仅限于 ASCII。 |
| **编码膨胀率** | 每个字节的十六进制表示为 2 个字符，每个字符可能映射为 1 或 2 个索引，最坏情况下原始字节数 × 4 个汉字（平均情况）。 |
| **无需密钥** | 编码不依赖密钥，属于公开的可逆编码，而非加密。 |

### 六、代码实现要点

在实际编写编码解码器时，需要注意：

1. **随机数生成**：使用 `random` 模块，确保每次编码时随机选择规则。
2. **反向映射表**：建立词汇到索引的字典 `{'富强':0, '民主':1, ...}` 便于快速查表。
3. **错误处理**：解码时需检查编码串长度是否为偶数，每个词汇是否在映射表中，索引序列是否合理（如 `10` 后必须还有元素）。
4. **UTF-8 编解码**：使用 Python 的 `bytes.fromhex()` 和 `.decode('utf-8')` 进行转换。
5. **大小写处理**：十六进制字符统一为大写，便于处理。

### 七、应用场景

- CTF 中隐写题（Steganography）的常见题型，需识别核心价值观编码并解码。
- 趣味信息隐藏，例如将敏感词替换为看似正常的核心价值观词汇。
- 作为学习编码/解码的入门案例，理解字符映射和可逆变换的思想。

### 八、总结

社会主义核心价值观编码是一种巧妙的自定义编码方案，其核心在于将 UTF-8 字节的十六进制表示拆分为单个十六进制数字，并通过两种随机规则将其映射到固定的 12 个词汇索引。解码时利用索引的前导标记（10 或 11）自动识别规则，从而还原原始数据。这种编码方式兼具趣味性和实用性，适合作为密码学或 CTF 初学者的练习项目。
