# MISC-眼见非实-解题思路
先检查一下`file.zip`的文件头信息,然后解压到`export`目录下.
```bash
$ file file.zip
file.zip: Zip archive data, at least v2.0 to extract, compression me
thod=deflate
$ unzip file.zip -d export
Archive:  file.zip
  inflating: export/眼见非实.docx  
$ tree export
export
└── 眼见非实.docx

0 directories, 1 file
```
我们来检查一下`export/眼见非实.docx`的文件头和文件二进制内容.
```bash
$ file export/眼见非实.docx
export/眼见非实.docx: Zip archive data, at least v1.0 to extract, co
mpression method=store
$ strings export/眼见非实.docx | rg flag
$
```
使用wps打开这个`export/眼见非实.docx`发现内容是看不懂的符号的乱码.

其实`docx`格式本质就是一种`zip`压缩包.`file`命令已经告诉了我们这一点.
