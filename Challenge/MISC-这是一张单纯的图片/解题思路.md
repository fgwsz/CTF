# MISC-这是一张单纯的图片-解题思路
首先使用`file`命令查看图片文件的文件头是否正常:
```bash
file file.jpg
```
```
file.jpg: JPEG image data, JFIF standard 1.01, resolution (DPI), density 96x96, segment length 16, baseline, precision 8, 136x152, components 3
```
看来是正常的,然后使用`StegSolve`打开看一下帧偏移信息,检测是否有图片隐写内容.
```
javax.imageio.IIOException: Unsupported marker type 0x26
```
这个就不太正常了,看来图片内部隐藏了二进制信息:
`0x26`是`ASCII`编码`&`字符的二进制.

使用`strings`命令查看一下图片的二进制字符显示,寻找可疑的`&`.
```bash
strings file.jpg
```

最后一行发现了可疑的`&#`标识.

`&#`是`HTML 实体编码unicode`的常用标识,编写`python`脚本进行解码:
```bash
echo '&#107;&#101;&#121;&#123;&#121;&#111;&#117;&#32;&#97;&#114;&#101;&#32;&#114;&#105;&#103;&#104;&#116;&#125;' | python3 -c "import sys, html; print(html.unescape(sys.stdin.read()))"
```

