```
描述:bugku{}
```
资源:
`file.zip`

## 解题过程
检查一下`file.zip`的文件头信息以及是否包含二进制文件追加隐写.
```bash
$ file file.zip 
file.zip: Zip archive data, at least v2.0 to extract, compression method=deflate

$ binwalk file.zip 

DECIMAL       HEXADECIMAL     DESCRIPTION
--------------------------------------------------------------------------------
0             0x0             Zip archive data, at least v2.0 to extract, compressed size: 35423, uncompressed size: 46894, name: admin.exe
35553         0x8AE1          End of Zip archive, footer length: 22
```
一切正常,使用资源管理器查看`file.zip`的备注信息:没有备注信息.

查找`file.zip`二进制信息中是否包含`bugku{}`或者`flag{}`.
```bash
$ strings file.zip | rg bugku 

$ strings file.zip | rg flag

```
将`file.zip`解压到`export`目录下:
```bash
$ unzip file.zip -d export
Archive:  file.zip
  inflating: export/admin.exe        

$ tree export/
export/
└── admin.exe

0 directories, 1 file
```
检查一下`export/admin.exe`的文件头信息以及是否存在二进制文件追加隐写.
```bash
$ file export/admin.exe 
export/admin.exe: ASCII text, with very long lines (46894), with no line terminators

$ binwalk export/admin.exe 

DECIMAL       HEXADECIMAL     DESCRIPTION
--------------------------------------------------------------------------------

```
这里变得不合理.`export/admin.exe`的后缀名是一个伪装,实际上是一个`txt`文本文件.
使用`vim`查看一下`export/admin.exe`的文件内容:
```txt
data:image/png;base64,# 这里是图片的base64数据,省略...
```
初见端倪,但是我们本着不放过任何一种可用信息的态度,
继续查看`export/admin.exe`的二进制字符串是否包含`flag`信息:
```bash
$ strings export/admin.exe | rg bugku

$ strings export/admin.exe | rg flag

```
接下来使用资源管理器查看`export/admin.exe`的备注信息:没有备注信息.

这样,我们就锁定了一种解法:
撰写`decode_admin_exe.py`脚本,将`base64`编码的图片数据解码后,二进制方式写入`output.png`中:
```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import base64
import os

def decode_admin_exe():
    input_file = "export/admin.exe"
    output_file = "output.png"

    # 检查输入文件是否存在
    if not os.path.isfile(input_file):
        print(f"错误：找不到文件 {input_file}")
        return

    # 读取文件内容（文本模式）
    with open(input_file, "r", encoding="utf-8") as f:
        content = f.read().strip()

    # 查找 base64 数据起始位置
    # 格式为 "data:image/png;base64,<base64_data>"
    prefix = "data:image/png;base64,"
    if content.startswith(prefix):
        b64_data = content[len(prefix):]
    else:
        # 兼容没有前缀的情况，直接当作纯 Base64
        b64_data = content

    # 解码 Base64
    try:
        img_data = base64.b64decode(b64_data)
    except Exception as e:
        print(f"Base64 解码失败: {e}")
        return

    # 写入二进制文件
    with open(output_file, "wb") as f:
        f.write(img_data)

    print(f"成功！图片已保存为 {output_file}")

if __name__ == "__main__":
    decode_admin_exe()
```
