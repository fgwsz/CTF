# MISC-隐写3
题目描述:
```
flag{}
```
资源:
`file.zip`
## 解题过程
检查`file.zip`的文件头信息和是否有二进制信息追加.
```bash
$ file file.zip 
file.zip: Zip archive data, at least v2.0 to extract, compression method=deflate

$ binwalk file.zip 

                                         CTF/Challenge/MISC-隐写3/file.zip
----------------------------------------------------------------------------------------------------------------------------------------
DECIMAL                            HEXADECIMAL                        DESCRIPTION
----------------------------------------------------------------------------------------------------------------------------------------
0                                  0x0                                ZIP archive, file count: 1, total size: 150083 bytes
----------------------------------------------------------------------------------------------------------------------------------------

Analyzed 1 file for 85 file signatures (187 magic patterns) in 2.0 milliseconds
```
使用资源管理器查看`file.zip`的备注信息:没有备注信息.

检查一下`file.zip`的二进制信息是否包含`flag`字符串.
```bash
$ strings file.zip | rg flag
$
```
看来没有,接下来解压`file.zip`到`export`目录下.
```bash
$ unzip file.zip -d export
Archive:  file.zip
  inflating: export/dabai.png        

$ tree export
export
└── dabai.png

0 directories, 1 file
```
检查一下`export/dabai.png`的文件头信息和是否有二进制追加隐写.
```bash
$ file export/dabai.png 
export/dabai.png: PNG image data, 679 x 256, 8-bit/color RGBA, non-interlaced

$ binwalk export/dabai.png 

                                     CTF/Challenge/MISC-隐写3/export/dabai.png
----------------------------------------------------------------------------------------------------------------------------------------
DECIMAL                            HEXADECIMAL                        DESCRIPTION
----------------------------------------------------------------------------------------------------------------------------------------
0                                  0x0                                PNG image, total size: 150560 bytes
----------------------------------------------------------------------------------------------------------------------------------------

Analyzed 1 file for 85 file signatures (187 magic patterns) in 2.0 milliseconds
```
接下来使用资源管理器查看一下`export/dabai.png`的备注信息:加载备注信息失败.

这里开始变得很可疑了.

检查一下`export/dabai.png`的二进制信息是否含有`flag`字符串.
```bash
$ strings export/dabai.png | rg flag
$
```
使用图片查看器打开`export/dabai.png`.
出现如下错误:
```
Could not load image "dabai.png"
Failed error reading PNG image file:IHDR:CRC error
```
这个错误一看就是出题人修改了`export/dabai.png`的`IHDR`文件头,
可能修改了图片的分辨率信息,但是没有根据新的分辨率计算`CRC`,
导致`CRC`校验一致性不通过.

使用工具`fix_png_ihdr.png`暴力修复图片分辨率.
```bash
$ python3 ../../Tools/MISC-fix_png_ihdr/fix_png_ihdr.py export/dabai.png 
[+] 找到匹配! 宽度: 679, 高度: 479
[+] 新IHDR数据: 000002a7000001df0806000000
[+] 修复完成，保存为: fixed_dabai.png
[+] 找到匹配! 宽度: 679, 高度: 479
[+] 新IHDR数据: 000002a7000001df0806000000
[+] 修复完成，保存为: fixed_dabai.png
```
使用图片查看器打开`fixed_dabai.png`,
图片内容如下:

![](fixed_dabai.png)

发现图片中的`flag{he1l0_d4_ba1}`.

尝试提交,提交通过,答题结束.
