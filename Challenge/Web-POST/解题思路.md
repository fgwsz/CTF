# Web-POST-解题思路

目标网址是`http://160.202.254.160:16722/`

打开开发者工具,查看`源代码`选项卡下的网址>索引内容:
```html
$what=$_POST['what'];<br>
echo $what;<br>
if($what=='flag')<br>
echo 'flag{****}';<br>
```
与`Web-GET`这个题目比较:只是把`GET`请求,改为了`POST`请求.

这意味着不能再通过直接在浏览器地址栏输入 ?what=flag 来获取 Flag 了
(因为地址栏访问默认是 GET 请求).

必须发送一个 POST 请求,并将参数 what 放在请求体(Body)中.

编写一个`post.py`
```python
import requests

url = "http://160.202.254.160:16722/"
payload = {"what": "flag"}

# 模拟浏览器请求头(可选,但建议加上)
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/150.0.0.0 Safari/537.36 Edg/150.0.0.0",
    "Content-Type": "application/x-www-form-urlencoded",  # POST 表单格式
}

response = requests.post(url, data=payload, headers=headers)

# 判断是否成功拿到 flag
if "flag{" in response.text:
    print("✅ 成功获取 Flag:")
    print(response.text)
else:
    print("❌ 未找到 Flag,返回内容如下:")
    print(response.text)
```
执行看一下.
```bash

✅ 成功获取 Flag:
$what=$_POST['what'];<br>
echo $what;<br>

echo 'flag{****}';<br>

```
至此,答题结束.
