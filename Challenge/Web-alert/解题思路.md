# Web-alert-解题思路

题目给出了一个网址:<http://160.202.254.160:13196>

这个网址的行为:
alert显示一个提示框(提示框1):包含一句提示词和一个按钮,鼠标左键单击按钮后,
alert显示另一个提示框(提示框2):包含一句提示词和一个按钮,鼠标左键单击按钮后,
alert重新显示提示框1.至此达成无限循环.

我使用开发人员工具打开之后,发现提示框挡住了我的开发人员工具界面的选项卡.
无法点击元素和源代码选项卡.

使用`Ctrl+shift+d`快捷键将开发者工具窗口,分离为底部窗口.
这时我点击元素和源代码选项卡,发现没有任何内容.

因此推测是`alert()`阻塞了当前网页.

我关闭了网址,使用`view-source:`方式直接访问网页的`html`源代码.

在浏览器新建选项卡网址栏输入`view-source:http://160.202.254.160:13196`.

打开之后,可以直接查看网页源代码,使用鼠标全选复制全部内容保存为`index.html`.

当然也可以直接鼠标右键另存为`index.html`,但是会遇到含有`&amp;`的二次`html`编码问题.

查看`index.html`文件发现如下可以的注释内容:
```html
<!-- &#102;&#108;&#97;&#103;&#123;&#102;&#100;&#51;&#55;&#102;&#51;&#49;&#54;&#97;&#53;&#98;&#101;&#97;&#99;&#49;&#48;&#101;&#56;&#101;&#56;&#99;&#102;&#52;&#57;&#56;&#51;&#101;&#98;&#53;&#55;&#97;&#101;&#125; --></script>  
```
使用`html`解码器解码,得到`flag{}`.
```bash
$ echo "&#102;&#108;&#97;&#103;&#123;&#102;&#100;&#51;&#55;&#102;&#51;&#49;&#54;&#97;&#53;&#98;&#101;&#97;&#99;&#49;&#48;&#101;&#56;&#101;&#56;&#99;&#102;&#52;&#57;&#56;&#51;&#101;&#98;&#53;&#55;&#97;&#101;&#125;" | python3 -c "import sys, html; print(html.unescape(sys.stdin.read()))"
flag{fd37f316a5beac10e8e8cf4983eb57ae}
```

## 拓展知识点:`&amp;`是什么?

如上所说,直接使用另存为保存`view-source`网页,
会遇到含有`&amp;`的二次`html`编码问题.

`&amp;`就是字符`&`的`html`编码后的结果.

举例:对`&#102`再进行一次`html`编码,就得到`&amp;#102`.

```html
&amp;#102;&amp;#108;&amp;#97;&amp;#103;&amp;#123;&amp;#102;&amp;#100;&amp;#51;&amp;#55;&amp;#102;&amp;#51;&amp;#49;&amp;#54;&amp;#97;&amp;#53;&amp;#98;&amp;#101;&amp;#97;&amp;#99;&amp;#49;&amp;#48;&amp;#101;&amp;#56;&amp;#101;&amp;#56;&amp;#99;&amp;#102;&amp;#52;&amp;#57;&amp;#56;&amp;#51;&amp;#101;&amp;#98;&amp;#53;&amp;#55;&amp;#97;&amp;#101;&amp;#125;
```
此时也就是需要使用`html`解码器解码2次才能得到可以阅读的`utf8`字符串.

此时,可以直接使用`decode_html_entities.py`进行循环`html`解码.
```bash
$ echo '&amp;#102;&amp;#108;&amp;#97;&amp;#103;&amp;#123;&amp;#102;&amp;#100;&amp;#51;&amp;#55;&amp;#102;&amp;#51;&amp;#49;&amp;#54;&amp;#97;&amp;#53;&amp;#98;&amp;#101;&amp;#97;&amp;#99;&amp;#49;&amp;#48;&amp;#101;&amp;#56;&amp;#101;&amp;#56;&amp;#99;&amp;#102;&amp;#52;&amp;#57;&amp;#56;&amp;#51;&amp;#101;&amp;#98;&amp;#53;&amp;#55;&amp;#97;&amp;#101;&amp;#125;' | python3 ..\..\Tools\Web-decode_html_entities\decode_html_entities.py
flag{fd37f316a5beac10e8e8cf4983eb57ae}
```
至此,解题完毕.
