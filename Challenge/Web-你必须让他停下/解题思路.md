# Web-你必须让他停下-解题思路

打开开发者工具:选择`源代码`选项卡,查看网页的`html`源码.
```html
<html>
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="">
<meta name="author" content="">
<title>Dummy game</title>
</head>

<script language="JavaScript">
function myrefresh(){
window.location.reload();
}
setTimeout('myrefresh()',500); 
</script>
<body>
<center><strong>I want to play Dummy game with others£¡But I can't stop!</strong></center>
<center>Stop at panda ! u will get flag</center>
<center><div><img src="2.jpg"/></div></center><br><a style="display:none">flag is here~</a></body>
</html>
```
发现这个网页的功能是定时进行网页刷新,而且每次刷新之后,如下行会刷新.
```html
<center><div><img src="2.jpg"/></div></center><br><a style="display:none">flag is here~</a></body>
```
我的解决思路,是在如下行设置一个断点(字符O的位置).
```html
    function myrefresh(){
O   window.location.reload();
    }
    setTimeout('myrefresh()',500); 
```
频繁步进,最终刷新到如下信息.
```html
<html>
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="">
<meta name="author" content="">
<title>Dummy game</title>
</head>

<script language="JavaScript">
function myrefresh(){
window.location.reload();
}
setTimeout('myrefresh()',500); 
</script>
<body>
<center><strong>I want to play Dummy game with others£¡But I can't stop!</strong></center>
<center>Stop at panda ! u will get flag</center>
<center><div><img src="10.jpg"/></div></center><br><a style="display:none">flag{e6e685da0c65f8e091c8b7c18fec9df7}</a></body>
</html>
```
至此找到了`flag{e6e685da0c65f8e091c8b7c18fec9df7}`.

解题结束.
