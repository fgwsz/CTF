# Web-头等舱-解题思路
打开开发者工具,点击`源代码`选项卡,查看索引文件内容:
```html
<html>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />

<pre><br><br><br><br>什么也没有。<br><br>
</html>
```
然后点击`元素`选项卡,查看页面元素.发现页面上就是一行文字.

打开`网络`选项卡(如果没有这个选项卡,点击+号选择网络添加网络选项卡),
重新刷新网页,然后选中网址对应的状态`200`的网络请求:
鼠标右键点击复制>复制请求头,得到如下请求头信息:
```
GET / HTTP/1.1
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,image/webp,image/apng,*/*;q=0.8,application/signed-exchange;v=b3;q=0.7
Accept-Encoding: gzip, deflate
Accept-Language: zh-CN,zh;q=0.9,en;q=0.8,en-GB;q=0.7,en-US;q=0.6
Cache-Control: max-age=0
Connection: keep-alive
Host: 160.202.254.160:10763
Upgrade-Insecure-Requests: 1
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/150.0.0.0 Safari/537.36 Edg/150.0.0.0
```
还是选中整个网络请求,鼠标右键点击复制>复制响应头,得到如下响应头信息:
```
HTTP/1.1 200 OK
Date: Tue, 28 Jul 2026 02:30:09 GMT
Server: Apache/2.4.7 (Ubuntu)
X-Powered-By: PHP/5.5.9-1ubuntu4.6
Flag: flag{0b6130f8c5835e72a6575117b73a0bc8}
Vary: Accept-Encoding
Content-Encoding: gzip
Content-Length: 129
Connection: close
Content-Type: text/html
```
至此,发现`flag{0b6130f8c5835e72a6575117b73a0bc8}`,答题结束.
