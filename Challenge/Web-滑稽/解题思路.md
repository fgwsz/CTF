# Web-滑稽
打开测试环境,浏览器`设置>更多工具>开发者工具`.

然后点击`</>Element`选项卡,查看网页元素内容:

发现了如下的注释:
```html
<!--flag{f6c532c7eb10d86c53a1e609f42d9dee}
 -->
```
至此,解题完毕.

如果不是那么直观就可以看到呢?
鼠标右键单击`</html>`标签,选择`Copy>Copy Element`复制整个`html`到剪切板.

之后,可以把这些内容粘贴到`vim`空白标签页缓冲区,进行`/flag`查找.

或者将其内容复制到`index.html`中,然后使用`ripgrep`在这个文件中查找`flag`字符串

```bash
$ rg flag index.html
342:<!--flag{f6c532c7eb10d86c53a1e609f42d9dee}
```
